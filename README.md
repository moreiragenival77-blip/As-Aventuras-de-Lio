# As Aventuras de Lio — Android

Projeto Android que empacota a edição expandida de poderes do jogo em um aplicativo nativo com WebView local.

## Gerar o APK pelo GitHub
1. Crie um repositório chamado `As-Aventuras-de-Lio`.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. Abra a aba **Actions**.
4. Selecione **Android APK** e clique em **Run workflow** (ou aguarde o build após enviar os arquivos).
5. Quando o workflow ficar verde, abra a execução e baixe o artefato **As-Aventuras-de-Lio-APK**.

O APK gerado será `app-debug.apk`. Esta é uma compilação de teste/instalação direta, não uma versão assinada para publicação na Play Store.
